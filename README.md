#### NanoShape3D: Automated 3D Morphology Reconstruction System for Nanomaterials from Single 2D Electron Microscopy Images

We propose NanoShape3D, an automated software solution that bridges the gap between 2D imaging and 3D analysis using deep learning. 
The goal is to provide a non-destructive, high-throughput tool for material scientists to infer 3D structures from standard archival or new microscopy data.
